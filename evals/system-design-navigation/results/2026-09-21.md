  summary attracting "duplicates". Narrowing that summary changed nothing: the
  agent still opened the concurrency page first. The cause was on the other

  symptom was "retries caused double charges" had nothing on the landing page

  summary of the question it should have reached, not only the one it reached.

  the job-runs-twice case and did not hurt `SDN-09`.

  and no longer relies on the agent's own judgment, which is what the previous
  run flagged.
