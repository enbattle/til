# Specs

One file per feature that went through the process in
[docs/SDLC.md](../SDLC.md) — the approved spec, saved once Stage 1 of
`.claude/skills/feature/SKILL.md` finishes, as a durable record of what
was built and why. Named `<slug>.md`, kebab-case, matching the feature.

A spec is a point-in-time record (plus any `## As built` section `/feature`'s
Stage 3 appends for deviations): it is not kept current after the feature
lands. For how things stand now, read `CLAUDE.md`, `src/content/registry.ts` and
the code.
